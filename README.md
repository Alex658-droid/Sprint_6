
# Sprint 6: Автотесты сервиса «Учебный тренажёр Самокат»

Проект автотестов для веб-сервиса заказа самоката (учебный стенд Яндекс.Практикума).  
Тесты написаны на Python + pytest + Selenium + Allure.

## Что покрыто тестами

- Позитивный сценарий оформления заказа (2 точки входа: верхняя и нижняя кнопки «Заказать», 2 набора данных).
- Проверка модальных окон и редиректов.
- Навигация по логотипам: «Самокат» → главная, «Яндекс» → Дзен.
- Проверка ответов в блоке FAQ.

## Как запустить

1. Активировать виртуальное окружение:
   ```powershell
   venv\Scripts\Activate.ps1

2. Установить зависимости (если ещё не установлены):
   ```powershell
   pip install -r requirements.txt
3. Запустить все тесты и сгенерировать Allure-отчёт:
   ```powershell
   python -m pytest tests/ -v --alluredir=allure-results
4. Открыть отчёт:
   ```powershell
   allure serve allure-results

Структура проекта
tests/ — тестовые сценарии.
pages/ — Page Object классы.
locators/ — локаторы элементов.
data.py — тестовые данные.
utils/ — вспомогательные методы.
